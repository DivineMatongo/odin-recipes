# odin-recipes
First practice project for The Odin Project

In this project, I am going to build a basic recipe website. The website will
consist of a main index page which will have links to a few recipes.

In this project, I seek to solidify my understanding of the following concepts:
    1. Basic Linux Terminal commands for working with files and folders.
    2. Creating and cloning a GIT repository.
    3. Pushing commits to my GIT repository while working on a project.
    4. Practicing making atomic commits with good commit messages.
    5. Working with basic HTML files to create a simple local website.
    6. Using tags efficiently to present text.
    7. Linking both internal and external pages and images into my webpages.
