# odin-recipes
First practice project for The Odin Project

In this project, I am going to build a basic recipe website. The website will <br />
consist of a main index page which will have links to a few recipes.

In this project, I seek to solidify my understanding of the following concepts: <br />
    1. Basic Linux Terminal commands for working with files and folders. <br />
    2. Creating and cloning a GIT repository. <br />
    3. Pushing commits to my GIT repository while working on a project. <br />
    4. Practicing making atomic commits with good commit messages. <br />
    5. Working with basic HTML files to create a simple local website. <br />
    6. Using tags efficiently to present text. <br />
    7. Linking both internal and external pages and images into my webpages. <br />
